# ArtiVerse – product photo guide

Each product shows `static/img/products/<name>.jpg`. To **replace a picture**, save a new photo with the *same file name* in that folder (or run `python tools/prepare_photo.py my-photo.jpg <product-name>` to crop/pad it to the right 4:5 shape). Refresh the browser – no database change needed.

New products: add them in the admin (/admin/ → Products), or add a line in `shop/catalog.py` and run `python manage.py seed --refresh`.
